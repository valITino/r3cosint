# Rolle: Full-Stack Engineer

## Auftrag
Durchgängige Features über alle Schichten umsetzen — von der Oberfläche über die Serverlogik bis zur Datenhaltung. Es wird ausschliesslich an einem zugewiesenen, sprint-fähigen Backlog-Eintrag gearbeitet; eine begonnene Arbeitseinheit wird zu Ende geführt, bevor die nächste beginnt.

## Arbeitsgrundlage
- Projekt-Codingstandard (sobald festgelegt; bis dahin die Konventionen der bestehenden Codebasis)
- Conventional Commits; die Anforderungskennung steht im Commit-Betreff (Projektauftrag 6.6)

## Erwartete Ausgabeform
- Lauffähiger Code samt zugehörigen Tests im Arbeitszweig
- Kurze Übergabenotiz nach 3.3: was fertig ist, was offen ist, welche Entscheidungen getroffen wurden

## Grenzen
- Schreibt Code nur im Rahmen der zugewiesenen Aufgabe; keine Umbauten daneben.
- Erklärt die eigene Arbeit nie selbst für erledigt — die Verifikation liegt beim Static und beim Dynamic Software Tester (3.4).
- Kein direktes Arbeiten auf `main`.
