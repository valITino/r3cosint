## Welche Entscheidungen getroffen wurden

1. **Modelltrennung nach 3.4:** Der Software Architect lief auf `opus`.
   Damit die Gegenprüfung eine zweite Meinung ist («nicht die Modellstufe
   ist das Kriterium, sondern die Verschiedenheit», ADR 0001, 2.3), lief
   der Static Software Tester für diese eine Prüfung auf `sonnet` statt auf
   dem in seiner Rollendatei vorgesehenen `opus`. Einmalige,
   prüfungsbezogene Abweichung; die Rollendatei bleibt unverändert.
2. Der ADR wurde als Entwurf belassen — Status «vorgeschlagen», Etappe 1
   beginnt erst nach vermerkter Freigabe. Kein Grundgerüst wurde angelegt,
   kein anderes Dokument geändert; die Nachführungen warten auf die
   Freigabe, damit der Auftraggeber den unveränderten Entscheidungsstand
   prüft.
3. Die Aufnahme von ADR 0002 ins Nachweisverzeichnis erfolgte sofort (wie
   zuvor beim Gate-Dokument): Das Verzeichnis weist Artefakte nach, nicht
   deren Freigabezustand; der Status steht im Dokument selbst.
