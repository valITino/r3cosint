# Anforderung R3-Q-001, offener Punkt O-15. Grundlage: ADR 0002, 6.8, Nachtrag vom 2026-10-28, und
# docs/uebergaben/2026-10-28_d8-freigabe-grundgeruest-g0-belegpruefer.md, Abschnitt "Einheit G0", Punkt 2b.
#
# FORM: je Zeile fuenf Felder, getrennt durch genau vier Tabulatoren; nur ASCII (keine Umlaute):
#   Kennung BM-nnn <TAB> Klasse (KB-, KC- oder EB-Kennung) <TAB> sed-Ausdruck <TAB> Mindestsatz <TAB> Grund
#   - Kennung: dauerhaft, nie wiederverwendet. Klasse: die Fehlerklasse oder Eigenschaft, die die Mutation treffen soll.
#   - sed-Ausdruck: wird mit sed -E --sandbox (e, r und w verboten) auf eine Wegwerfkopie des Pruefers angewandt (nicht auf das Pruefmittel); er darf keinen
#     Tabulator enthalten und soll an einem Anker im Code des Pruefers haften, nicht an Kommentarzeilen.
#   - Mindestsatz: Fallkennungen B-nnn durch Komma, mindestens eine; nur diese Faelle laufen gegen die Mutante. Knapp halten (ein
#     bis drei Faelle), damit der Modus schnell bleibt. Ein Fall mit Soll arbeitsbaum (B-190) steht in keinem Mindestsatz.
#   Zeilen mit # am Anfang und Leerzeilen werden uebergangen.
# AUSGANG JE MUTATION: ERKANNT, wenn jeder Fall des Mindestsatzes gegen die Mutante faellt. WIRKUNGSLOS, wenn die Kopie
#   byte-gleich mit dem Pruefer ist, bash -n sie verwirft oder sed mit einem Fehler endet. NICHT_ERKANNT sonst (auch wenn ein Fall
#   des Mindestsatzes nicht herstellbar ist). Der Modus endet mit 0 nur ohne nicht erkannte und ohne wirkungslose Mutation.
# DECKUNG (mechanisch, Abweichung ergibt 2): jede Klasse KB, KC und EB im Kopfkommentar des Pruefers hat mindestens eine Mutation,
#   deren Mindestsatz einen Fall dieser Klasse enthaelt; die Klasse jeder Zeile gehoert zu einem Fall ihres Mindestsatzes. Die
#   Grenzen GB tragen keine Pflichtmutation.
# PFLEGE: Aendert sich der Pruefer so, dass ein Anker nicht mehr trifft, meldet der Modus die Mutation als wirkungslos; die Zeile
#   wird angepasst, nicht gestrichen. Eine neue Klasse im Kopfkommentar braucht Faelle und mindestens eine Mutation. Neue Zeilen
#   erhalten die naechste freie Kennung am Ende der Datei. GRENZE des Modus: Eine Mutation, die das Urteil nicht aendert, ist
#   nicht erkennbar. Das Entfernen der Regel "mehr als 9 Stellen" in zeilen_ok ist so eine aequivalente Mutante, weil der
#   fail-closed Vergleich dasselbe Urteil traegt; die Regel hat darum nur die Umkehr als Mutation.
#
