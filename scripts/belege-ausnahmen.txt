# Ausnahmeliste für scripts/belege-pruefen.sh
#
# Aufbau je Zeile: der Schlüssel, ein Tabulator, der Grund. Leerzeilen und
# Zeilen mit # am Anfang werden übergangen.
#
# DER SCHLÜSSEL IST ORTSGEBUNDEN. Zwei Formen sind zulässig:
#   datei:zeile   — genau dieser Fundort, jeder Wert dort
#   datei|wert    — dieser Wert in dieser Datei, zeilenunabhängig
# Eine dritte Form gibt es nicht; ein blosser Wert ohne Datei ist selbst ein
# Befund (Art "ausnahme-form"). Grund: Eine wertgebundene Ausnahme
# unterdrückte jedes künftige Vorkommen desselben Wortlauts im ganzen
# Bestand — auch einen echten neuen Fehler. Die Nachprüfung vom 2026-09-01
# hat das an zwei eingebauten Fällen belegt.
#
# Zwei weitere Prüfungen greifen an dieser Datei selbst:
#   — Ein Eintrag ohne Grund ist ein Befund. Eine Ausnahme ohne Begründung
#     ist eine Lücke mit Deckmantel.
#   — Ein Eintrag, dessen Gegenstand inzwischen existiert, ist ein Befund.
#     Dann gehört die Zeile hier weg, nicht stehen gelassen — sonst deckt sie
#     beim nächsten Mal etwas Echtes zu.
#
# Alle Einträge sind am 2026-09-01 einzeln am Bestand nachgeschlagen worden.
# Keiner der Funde war ein Fehler in einem Dokument.
