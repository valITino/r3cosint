# Anforderung R3-Q-001. Grundlage: ADR 0002, Abschnitt 5, Nachtrag vom 2026-11-04 (Festlegung fuer N3), Zeile "Mutationen und
# Mindestsaetze"; Muster: scripts/nachweise-vollstaendig-mutationen.txt und scripts/prototyp-trennung-pruefen-mutationen.txt. Einheit N3.2.
#
# FORM: je Zeile fuenf Felder, getrennt durch genau vier Tabulatoren; nur ASCII (keine Umlaute):
#   Kennung SM-nnn <TAB> Klasse (KS-Kennung) <TAB> sed-Ausdruck <TAB> Mindestsatz <TAB> Grund
#   - Kennung: dauerhaft, nie wiederverwendet. Klasse: die Fehlerklasse, die die Mutation treffen soll.
#   - sed-Ausdruck: wird mit sed -E --sandbox (e, r und w sind verboten) auf eine Wegwerfkopie des Makefile angewandt (nicht auf das
#     Pruefmittel); er darf keinen Tabulator enthalten und haftet an einer Codezeile des Rezepts, nicht an Kommentarzeilen. Als
#     Begrenzer dient die Tilde. "$$" im Muster ist die Schreibweise des Makefile fuer ein Dollarzeichen der Shell.
#   - Mindestsatz: Fallkennungen durch Komma; erkannt ist die Mutation, wenn jeder dieser Faelle gegen die Mutante faellt.
#   - Grund: ein Satz, was die Mutation aendert. Fuer eine Familie der Selbstpruefung beginnt er mit "Familie <name>:" (Gegenstandsdeckung).
# Ausnahme von der Regel "eine Zeile": SM-020, SM-021, SM-029 und SM-051 treffen gewollt mehrere Zeilen (SM-020, SM-021 und SM-029 beide Laeufe,
# SM-051 jede Stelle des Namens der Lage C gitleaks-historie); je Mutation steht im Feld Grund der Satz dazu. Die uebrigen aendern eine Zeile.
# Jede Mutante muss auf dem Geruest noch genau eine Marke liefern (sonst ist sie wirkungslos: Defekt der Mutation).
# Ohne Mutation bleiben (gleichwertig oder unerreichbar, siehe GS-5 und GP-S1 im Pruefmittel): die Systemkonfiguration von git
# (GIT_CONFIG_NOSYSTEM ist ueber das Umfeld der Aufrufe von gitleaks gemessen, SM-037) und das Teilmuster je Pfad der Familie bau-dateien
# (je Teilmuster ein Fall, eine Mutation fuer die ganze Familie, SM-010).
