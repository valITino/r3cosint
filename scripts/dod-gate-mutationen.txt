# ihre eigene Verneinung erkennt.
#
# Diese Datei ist die AUSFUEHRBARE Form der Spalte "Mutation" der Tabelle
# 6.12.19. Sie ist Spezifikation, nicht Werkzeug: gebaut und ausgefuehrt wird
# der Mutationsmodus vom DevOps Engineer, geprueft von Static und Dynamic
# Software Tester auf einem anderen Modell (3.4). Der Software Architect hat
# nichts davon ausgefuehrt.
#
# AUFBAU je Zeile, Felder durch EINEN Tabulator getrennt:
#   1 Kennung   Z-nnn aus der Tabelle 6.12.19
#   2 Ziel      dod-gate.sh | Makefile | dod-gate-terminierte-lagen.txt |
#               selbsttest
#   3 Mutation  sed-Ausdruck fuer eine KOPIE des Ziels, oder das Wort "keine"
#   4 Grund     die Aenderung in Worten (bei "keine": der Grund aus der
#               geschlossenen Liste in 6.12.26 b)
# Zeilen, die mit "#" beginnen, sind Kommentar. Leerzeilen werden uebergangen.
#
# WAS DER MUTATIONSMODUS TUT (Aufruf: scripts/dod-gate-selbsttest.sh
# --mutationen), in dieser Reihenfolge (6.12.26 b):
#   1. Deckung in beide Richtungen: jede nicht zurueckgezogene Kennung der
#      Tabelle 6.12.19 hat genau einen Eintrag hier, und jeder Eintrag hier
#      traegt eine Kennung der Tabelle.
#   2. Die Mutation wird auf eine KOPIE des Ziels angewandt; die Kopie MUSS
#      sich vom Original unterscheiden. Ein sed-Ausdruck, der nichts trifft,
#      ist selbst ein Befund und keine stille Nulloperation.
#   3. Der Fall der Kennung laeuft gegen die mutierte Kopie und MUSS genau
#      diese Kennung als FEHLGESCHLAGEN melden. Andere duerfen mitfallen.
# Der Pruefgegenstand selbst wird NIE veraendert -- mutiert wird ausschliesslich
# eine Kopie im Pruefaufbau.
#
# KONVENTIONEN der sed-Ausdruecke:
#   - Trennzeichen ist "#", damit Pfade mit "/" unmaskiert stehen koennen.
#   - Kein einziges Hochkomma (') im Ausdruck, damit der Aufrufer ihn ohne
#     Maskierungsakrobatik in Hochkommata setzen kann; ein Hochkomma im
#     Quelltext wird mit "." getroffen.
#   - "&" in der Ersetzung meint den Treffer; ein woertliches "&" steht als
#     "\&".
#   - Kein Tabulator innerhalb eines Feldes.
#
# Z-110 ist am 2026-09-03 zurueckgezogen (6.12.25 h) und hat deshalb KEINEN
# Eintrag; die Deckungspruefung nimmt zurueckgezogene Kennungen aus.
